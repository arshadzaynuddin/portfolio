# Portfolio

Building scalable enterprise solutions and robust backend architectures.

## Setup and Development

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run development server**:
    ```bash
    npm run dev
    ```

## Deployment

This project is configured for **Firebase Hosting**.

### How to Deploy

1.  **Build the project**:
    ```bash
    npm run build
    ```

2.  **Deploy to Firebase**:
    ```bash
    npm run deploy
    ```

*Note: Standard `firebase` commands are not installed globally. Always use `npm run deploy` or prefix commands with `npx` (e.g., `npx firebase init`).*
